## How this repo is organised

Each module has its own folder with its own README, so the detail lives next to the code.

- `linux-fundamentals/` – notes and screenshots from the Linux module and Bandit
- `bash-battle-arena/` – my solutions, one folder per level
- `bash-scripting/` – the scripting challenges, one folder per challenge
